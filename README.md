### 软件概述

`TodoFloat` 是一款运行于 Windows 平台的超低占用原生当日待办悬浮窗工具，基于 C++23、`User32`、`Direct2D`、`DirectWrite` 与 `DWM` 构建为无外部依赖的单文件可执行程序。窗口通过 `WS_EX_TOOLWINDOW` 扩展样式从 `Alt+Tab` 切换面板与任务栏中隐藏，静默状态下阻塞于系统消息队列，保持极低的内存占用与零 CPU 轮询开销。

### 窗口交互与形态切换

启动 `TodoFloat.exe` 后，悬浮窗默认置顶停靠在主屏幕右上区域。按住标题栏空白区域可自由拖拽位置，双击标题栏或点击右侧折叠图标可将面板上下收拢为单行进度条，再次双击或点击展开图标即可恢复完整清单高度。将窗口拖至当前显示器左边缘释放或点击标题栏的贴左图标，面板会收缩为紧贴屏幕左边界的竖向窄指示条；鼠标移入窄条时面板向右弹出，鼠标移出窗口且未处于文本录入状态满 `250ms` 后自动收回。

标题栏图钉图标与右键菜单支持随时切换窗口置顶状态。点击标题栏穿透图标、按下全局热键 `Alt + T` 或左键单击系统托盘图标，可在正常交互态与鼠标穿透态之间一键切换。开启鼠标穿透后，窗口呈现柔和半透明视觉提示并将全部鼠标点击与滚轮操作直接传递给下层窗口；再次按下 `Alt + T` 或左键单击系统托盘图标即可恢复正常鼠标交互。

在列表区域点击任意待办行即可切换完成状态，悬停行右侧可点击 `×` 删除条目；点击底部输入栏键入内容并按回车即可创建今日新待办，按 `Esc` 收起输入焦点。右键点击悬浮窗或系统托盘图标可打开完整控制菜单。

### AI 接入与每日日志持久化

程序在所在目录下维护固定的 `todo.md` 作为今日待办面板与 AI 协作入口，采用标准 UTF-8 Markdown 任务列表语法：

```markdown
# 2026-11-25

- [ ] 核对核心模块接口返回字段
- [x] 10:15 完成初版编译验证
```

点击标题栏的 `AI` 按钮可将包含 `todo.md` 绝对路径的接入说明复制到剪贴板，发给任意具备本地文件读写能力的 AI 代理或脚本即可实现直连。外部修改保存 `todo.md` 后，后台 `ReadDirectoryChangesW` 内核监听线程经 `50ms` 防抖唤醒界面同步刷新。

每次任务变更均实时同步至 `logs/YYYY-MM-DD.md`。当系统日期进入新的一天时，前一日的完成与未完成记录完整保存在对应的 `logs/` 日期文件中，`todo.md` 自动重置为新日期下的空白清单。点击标题栏的进度日志徽标可直接在资源管理器中打开 `logs/` 目录查阅每日记录。

### 编译与测试

在安装了 `MinGW-w64 GCC`（支持 C++23）的环境中，于项目根目录执行以下命令即可运行核心单元测试并编译单文件可执行程序：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```
